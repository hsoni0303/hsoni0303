## Hi, I'm Hemant Soni 👋

I build machine-learning systems in India, focusing on **robust ML**: models
that keep working when the data is noisy, corrupted or adversarial. My M.Tech
thesis is a time-series forecasting model that stays accurate when its
training data contains anomalies.

I like taking ideas from paper to working, tested code: data pipelines,
models, evaluation, and the MLOps around them.
